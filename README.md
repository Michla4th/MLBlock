# STEM Blockly App

A simple and fun mobile application to learn programming and control STEM microcontrollers (such as ML:bit).

---

## 🌟 Key Features

* 🧩 **Drag-and-Drop Coding**: Easy block-based programming for beginners. Control lights, motors, sensors, loops, logic, and more.
* 🐍 **Python Code View**: Switch anytime between visual blocks and real Python code to learn text programming.
* 📶 **Bluetooth Wireless Connection**: Scan and connect to your microcontroller via Bluetooth without cables.
* 🚀 **One-Tap Code Upload**: Upload and run your program on the board instantly with one click.
* 💬 **Built-in Terminal**: Send values and monitor real-time message logs from your device.
* 📁 **Project Manager**: Create, save, and organize multiple coding projects easily.
* 🎮 **Multi-Mode Support**: Includes modes for **Code**, **Play**, **Build**, and **IoT** applications.

## 🚀 How to Get Started

1. **Open the App**: Tap on **Code** from the main menu.
2. **Create a Project**: Click on **New Project (+)**.
3. **Build your Program**: Drag and drop blocks (or write Python code).
4. **Connect Device**: Tap the **Bluetooth icon** at the top right and select your board (e.g., `ML:bit`).
5. **Run**: Tap the **Play** button to upload and run your code!
